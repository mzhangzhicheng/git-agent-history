# Security policy

git-agent-history handles conversation transcripts that can contain sensitive data.
Please report vulnerabilities privately through GitHub's
"Report a vulnerability" button on the repository's Security tab rather than in a public issue.

Please do not include real transcripts or credentials in reports; a description and a
synthetic reproduction are enough.

The threat model, including what the tool does and does not protect against, is described
in the "Security and privacy" section of the README.
